# Tapi District Social Search 🔎

A free, district-focused public social media search interface for Tapi, Gujarat, India.

Search for publicly indexed content using taluka names, village names, keywords, and hashtags across popular search platforms.

## 🌐 Live Demo

https://krunal9797.github.io/tapi-social-search/

## ✨ Features

- Search content related to Tapi District, Gujarat.
- Select a taluka or enter a village name.
- Search using keywords, hashtags, or public post text.
- Filter by content type: posts, reels, news, and accounts.
- Select a time-related search term.
- Search through Google, Instagram, Facebook, YouTube, X, and Telegram.
- Generate search queries in a popup.
- Copy search queries.
- Responsive interface for desktop and mobile.
- Dark-themed user interface.

## 📍 Supported Areas

- Vyara
- Songadh
- Valod
- Uchchhal
- Dolvan

- Nizar
- Ukai and other Tapi District areas

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/krunal9797/tapi-social-search.git
   ```

2. Open the project folder:

   ```bash
   cd tapi-social-search
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

## 🌍 GitHub Pages Deployment

1. Open the repository on GitHub.
2. Navigate to **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder.
5. Click **Save**.

Live URL:

https://krunal9797.github.io/tapi-social-search/

## 🔐 Privacy and Limitations

- This project is a public search interface, not a live social media data scraper.
- Search results are provided by external search platforms.
- It does not access private accounts, private messages, or restricted content.
- Availability and completeness of results depend on each platform's search and indexing rules.
- No backend, database, or API is required for the basic interface.
